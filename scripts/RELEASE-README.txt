# Renown 0.1.0 发行包

Windows 10 2004+ / Windows 11（x64）

---

## 两个文件怎么选

| 文件 | 大小 | 适合 |
|---|---|---|
| `Renown_0.1.0-x64-setup.exe` | 18.5 MB | **推荐**。双击安装，自动创建开始菜单快捷方式，可在「设置 → 应用」里卸载 |
| `Renown-Portable-0.1.0-x64.exe` | 31.0 MB | 免安装绿色版。放到任意目录双击即用，不写注册表 |

两个都是**未签名**的 exe，Windows SmartScreen 首次运行时可能提示「未知发布者」，
点「更多信息 → 仍要运行」即可。

---

## 安装版

1. 双击 `Renown_0.1.0-x64-setup.exe`
2. 安装位置默认 `%LOCALAPPDATA%\Renown`（当前用户，不需要管理员权限）
3. 安装完从开始菜单打开 **Renown**
4. 卸载：设置 → 应用 → Renown → 卸载，或运行安装目录下的 `uninstall.exe`

静默安装（脚本用）：`Renown_0.1.0-x64-setup.exe /S`

## 便携版

1. 把 `Renown-Portable-0.1.0-x64.exe` 放到你想要的位置（U 盘也行）
2. 双击运行
3. 删除该文件即完成「卸载」

两个版本共用同一份配置和数据（见下），所以可以随时互换。

---

## 数据存在哪

| 用途 | 路径 |
|---|---|
| 配置（便签、栅栏布局、规则） | `%APPDATA%\Renown` |
| 便签数据 | `%USERPROFILE%\Documents\Renown` |
| 图标缓存 | `%LOCALAPPDATA%\Renown\icon-cache` |

注意：卸载不会删除以上数据目录，方便重装后接着用。要彻底清除请手动删这三个目录。

---

## 第一次打开做什么

1. 主窗口是便签界面，可以直接新建笔记
2. 桌面整理：**设置 → 桌面整理**，打开管理窗口
3. 管理窗口里点「同步桌面」，把桌面文件收进来
4. 想自动归类就用「快速添加」里的模板（程序 / 文档 / 图片 / 下载 …）

栅栏操作：

- 双击图标 → 打开文件
- 双击标题 → 重命名栅栏
- 拖动图标 → 手动排序（需在「手动」排序模式下）
- 右键图标 → 移动到其它栅栏 / 移出栅栏
- 右键空白处或标题 → 切换视图 / 卷起 / 删除栅栏

---

## 系统要求

- Windows 10 2004+ 或 Windows 11
- **WebView2 运行时**（Win11 和大部分更新的 Win10 已预装；
  如果没有，安装器会提示，也可从微软官网下载 Evergreen Bootstrapper）
- x64 架构

---

## 已知限制

- 强制结束进程（任务管理器）时若开着「隐藏原生桌面图标」，桌面图标会保持隐藏，
  重新打开 Renown 即恢复。
- 不能从资源管理器把文件直接拖进栅栏窗口（为保证栅栏内拖拽排序可用），
  跨栅栏移动请用右键菜单的「移动到…」。
- exe 未做代码签名，SmartScreen 会提示。
